# AI Combat Arena

The AI Combat Arena is a Minecraft plugin that lets players engage in thrilling combat against AI bots and armies. This plugin is designed for players who enjoy competitive gameplay and want to test their skills against intelligent opponents. With customizable AI behaviors and a variety of combat scenarios, the AI Combat Arena offers an immersive and challenging experience.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Join your Minecraft server.
2. Use the command `/spawnbot` to spawn a single AI bot.
3. Use the command `/spawnarmy` to spawn a group of AI bots.
4. Engage in combat with the AI bots and try to defeat them.
